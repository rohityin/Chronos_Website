# Agent Instructions: Chronos

## Overview
- **Project Name**: Chronos
- **Stack**: React 19, TypeScript, Tailwind CSS v4, Vite, Lucide Icons, Canvas Confetti
- **Purpose**: Ultra-premium horology landing page and artisan reservation platform for the limited-edition hand-assembled Chronos Atelier No. 01 timepiece (25 pieces worldwide). Features microscopic craftsmanship inspection, raw steel/sapphire metallurgy showcase, interactive watchmaker loupe, bespoke configurator, live calibre metrics, multi-layer parallax depth animations, and high-value pre-order allocation.

## Development Commands
- Install dependencies: `npm install`
- Start dev server: `npm run dev`
- Build for production: `npm run build`
- Preview build: `npm run preview`

## Architecture & Conventions
- Entry point: `src/main.tsx` & `src/App.tsx`
- Components: `src/components/` (Hero, ParallaxShowcase, MovementLoupe, MetallurgyStory, BespokeConfigurator, ProvenanceLedger, PreorderModal, Navbar, Footer)
- Assets: `public/assets/` (hero_watch.jpg, escapement_macro.jpg, artisan_craft.jpg, metallurgy_raw.jpg, edition_damascus.jpg, edition_rosegold.jpg, caseback_calibre.jpg)
- Styling: Tailwind CSS v4 with custom horological palette (Obsidian, German Silver, Flame Blue, Rose Gold, Specular Steel)

## Project Rules
- Follow framework idiomatic patterns.
- Ensure all interactive controls have accessible tactile states.
- High-contrast, authentic horological typography with tabular numerals for precision metrics.
- Multi-layer parallax and scroll physics optimized for 60fps execution.
